# create-issue

ワーキングディレクトリ内の `issues/` に、統一テンプレートで新規 issue を 1 ファイル作成するスキル。

> issue の管理方法（`issues/` の構造、ステータスの遷移、編集ルール）は `agent-issues` に従う。

## 手順

### 1. 内容を把握する

会話の文脈から、次の情報を抽出する。

- **タイトル**: 何についての issue か（1 行・簡潔に）
- **種別**: `bug` / `feature` / `task` / `docs` / `question` のいずれか
- **概要・背景**: なぜ必要か、何が問題か
- **詳細**: 再現手順、要件、仕様など

文脈から推測できる項目は聞き返さず埋める。**タイトルや概要が全く分からない場合のみ**、ユーザーに 1 回だけ質問する。推測できなかった項目は無理に創作せず、`未定` または `（未記入）` とする。

### 2. issues/ ディレクトリを用意する

ワーキングディレクトリ（カレントディレクトリ）直下の `issues/` を使う。存在しなければ作成する。

```bash
mkdir -p issues
```

### 3. ファイル名を決める

形式: `issues/NNNN-<slug>.md`

- `NNNN`: 4 桁ゼロ埋めの連番。`issues/` 内の既存ファイルの先頭番号の最大値 + 1（既存がなければ `0001`）
- `<slug>`: タイトルを英小文字・数字・ハイフンにした短い名前（最大 50 文字程度）。日本語タイトルの場合は内容を表す英語の slug を付ける

例: `issues/0003-fix-login-timeout.md`

既存の最大番号は次のように確認する。

```bash
ls issues/ 2>/dev/null | grep -oE '^[0-9]{4}' | sort -n | tail -1
```

既存ファイルは上書き・改名・削除しない。

### 4. テンプレートに沿って作成する

下記テンプレートを使い、`{...}` を埋める。日付は `date +%Y-%m-%d` で取得した実際の日付を使う。**見出し構成は変えない**（種別に不要な節は「該当なし」と書く）。

```markdown
# {NNNN}: {タイトル}

| 項目 | 内容 |
|------|------|
| ID | {NNNN} |
| 種別 | {bug / feature / task / docs / question} |
| ステータス | open |
| 優先度 | {high / medium / low} |
| 作成日 | {YYYY-MM-DD} |
| ブランチ | {issue-NNNN-slug} |
| 承認日 | 未承認 |
| ラベル | {label1, label2} |

## 概要

{何についての issue かを 2〜3 文で}

## 背景・動機

{なぜこの issue が必要か。現状の問題や目的}

## 詳細

{bug の場合: 再現手順・発生環境・実際の挙動}
{feature / task の場合: 要件・仕様・設計メモ}

### 期待する挙動

{あるべき状態}

## 受け入れ条件

- [ ] {完了と判断できる条件 1}
- [ ] {完了と判断できる条件 2}

## 関連

- 関連ファイル: {path/to/file}
- 関連 issue: {#NNNN}
- 参考リンク: {URL}

## メモ

{補足、検討事項、未解決の疑問}
```

### 5. 報告する

作成後、次を簡潔に伝える。

- 作成したファイルのパス
- 設定した種別・優先度（推測で決めた項目はその旨）

ファイル全文を繰り返し表示する必要はない。

## ルール

- 作成先は常にワーキングディレクトリ直下の `issues/`。他の場所には作らない。
- 1 回の呼び出しで作る issue は、ユーザーが複数依頼した場合を除き 1 件。
- ステータスの初期値は常に `open`。`ready` 以降は polish-issue 以降の工程が扱うため、このスキルでは `open` 以外にしない（ステータスの定義と遷移は agent-issues を参照）。
- ブランチ名は、agent-git の規約に従う。
- 承認日は常に `未承認` とする（承認は人間が polish-issue のレビューで行う）。
- 優先度が不明な場合は `medium` とする。
- コードの修正や調査は、依頼されていない限りこのスキルでは行わない（起票のみ）。
